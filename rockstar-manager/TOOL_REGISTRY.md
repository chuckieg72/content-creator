# TMS Rockstar Manager — Tool Registry v0.1

This registry separates a business capability from the vendor providing it. Providers can be replaced without rewriting the Manager’s job.

| Capability | Current/possible provider | Status | Approval rule |
|---|---|---|---|
| Reasoning / management | ChatGPT | In use | Normal work allowed |
| Web research | ChatGPT web research | In use | Normal work allowed |
| Source/code storage | GitHub | Connected | Non-destructive project work allowed; review consequential changes |
| Speech / narration | Runway | Connected and tested | Use credits carefully; no plan upgrade without approval |
| Image generation | Runway / ChatGPT image tools | Available depending on task | Use approved/free credits; no upgrade without approval |
| Video generation/editing | Provider required | Current connected Runway workspace does not expose video models | No purchase/upgrade without approval |
| Email | Connected email tools when authorized | Available by task | External sending follows approval/tool rules |
| Website/app deployment | To be selected/connected | Candidate capability | No paid deployment/domain/billing without approval |
| Payments/checkout | To be selected from TMS approved processor | Not configured here | All financial/account setup requires Chuck approval |
| Affiliate/referral tracking | Provider-specific | Research/configure later | Never choose an inferior tool solely for commission |

## Selection rule
For every external capability evaluate:
1. Can it actually complete the required job?
2. Output quality/reliability.
3. Cost per usable result, not advertised credits alone.
4. API/plugin/agent accessibility.
5. Commercial-use terms.
6. Customer usability if this becomes a TMS product.
7. Affiliate/referral program, only after capability and value are established.
8. Ability to swap providers later.

## Spending rule
The Manager may estimate and recommend paid tool usage. It may not initiate a new purchase, subscription, upgrade, or billing change without Chuck’s explicit approval.
